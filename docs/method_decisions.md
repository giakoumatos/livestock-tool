# Method decisions

Choices where the sources leave room, with what the tool does now. Each is
listed in a run's open points when it affects the dataset.

Rule (user, 2026-10-22): use the most correct and most up-to-date method.
For each question that is the most recent primary source that covers it:
IPCC 2019 Refinement for greenhouse gases and N flows, EMEP/EEA 2023 for
NH3, NOx, NMVOC and particulate matter, SALCA v1.0.1 (Appendix 6) for
Switzerland, IDF 2022 for the dairy allocation, and WFLDB v3.5 for the
system boundaries (manure spreading belongs to the crops, pasture excreta
follow the land) and for what no newer source covers (water release, the
default allocations). Where a printed rule cannot hold for the case at hand,
the physically consistent reading is used and recorded here.
